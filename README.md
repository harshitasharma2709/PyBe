# PyBe — Original Scenario-Driven Python Learning Prototype

## About
PyBe is a small educational prototype that teaches beginner Python concepts through short lessons and practical scenarios.

## Features
- Beginner-friendly Python lessons
- Scenario-based multiple-choice challenges
- Immediate feedback
- Simple progress tracking
- No login/database required
- Runs locally with Streamlit

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Project structure

- `app.py` — main Streamlit interface
- `lessons.py` — original lesson content
- `scenarios.py` — original scenario questions
- `requirements.txt` — dependency list
